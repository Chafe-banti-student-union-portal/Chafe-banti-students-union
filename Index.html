ℹ️ Waa'ee Gamtaa Barattoota Magaalaa Caffee Bantii

CHAFE BANTI TOWN STUDENTS UNION | የጨፌ ባንቲ ከተማ ተማሪዎች ማህበር

🎯 Eergama (Mission)

Barattoota Magaalaa Caffee Bantii walitti fiduun, wal deeggaruun, barnoota isaanii keessatti milkaa'ina akka galmeessisan taasisuu; hawaasa isaanii tajaajiluun, naamusaa fi hoggansa gaarii horachuun, guddina magaalichaa keessatti gahee isaanii akka bahatan dandeessisuu.

🔭 Mul'ata (Vision)

Gamtaa barattootaa sadarkaa biyyaatti fakkeenya ta'e, barattoota beekumsaan, naamusaan, hojii tola ooltummaan fi tokkummaan cimsuun hawaasaaf bu'aa guddaa buusu ijaaruu.

📌 Kaayyoo Waliigalaa (General Objective)

Barattoota walitti qindeessuun barnoota, ogummaa, hojii tola ooltummaa fi waldeeggarsa cimsuun misooma dhuunfaa fi hawaasaa keessatti qooda isaanii guddisuu.

🎯 Kaayyoo Addaa (Specific Objectives)

  • Barattoota jidduutti tokkummaa fi wal kabajuu cimsuu.
  • Barattoota rakkoo dinagdee keessa jiran deeggaruu.
  • Barnoota dabalataa (tutorial) qopheessuun bu'aa barnootaa fooyyessuu.
  • Leenjii dandeettii jireenyaa fi hoggansaa kennuu.
  • Qulqullina naannoo fi hojii tola ooltummaa keessatti hirmaannaa guddisuu.
  • Beekumsa technologies fi afaanota garaagaraa babal'isuu.
  • Dhaabbilee mootummaa fi miti mootummaa waliin tumsa uumuu.

💎 Duudhaalee (Core Values)

Amanamummaa • Tokkummaa • Itti Gaafatamummaa • Haqaqabeessummaa • Kabajaa Waloo • Hojii Tola Ooltummaa • Hirmaachisummaa • Guddina Itti Fufaa

📜 Imaammata (Policy)

  • Seeraa fi mootummaa kabaja.
  • Amantii, sabaa fi siyaasaan walqooduu irraa bilisa ta'ee hojjeta.
  • Miseensota hunda walqixxummaan tajaajila.
  • Murtoo marii fi dimokraasiidhaan kenname hojiirra oolcha.
  • Qabeenya gamtaa iftoominaa fi itti gaafatamummaan bulcha.

🚀 Tarsiimoo (Strategy)

  • Miseensota haaraa galmeessuu fi hirmaachisummaa isaanii guddisuu.
  • Sagantaalee barnootaa fi leenjii yeroo yeroon qopheessuu.
  • Teknooloojii fi miidiyaa hawaasaa fayyadamuun qunnamtii cimsuu.
  • Hojii tola ooltummaa idilee geggeessuu.
  • Deeggarsa mootummaa, abbootii qabeenyaa fi miti-mootummaa irraa barbaaduu.
  • Bu'aa hojii yeroo yeroon madaaluu fi fooyyessuu.

🏆 Dhaadannoo (Motto)

"Barnootaan Milkoofna, Tokkummaan Ni Cimna, Hawaasa Keenya Ni Tajaajilla."

📜 Ulaagaalee Itti Bulmaata Gamtaa

Seera fi Qajeelfama Bulchiinsa Gamtaa Barattoota Magaalaa Caffee Bantii

Keewwata 1: Hundeeffama fi Maqaa

  • Gamtaan kun maqaa "Gamtaa Barattoota Magaalaa Caffee Bantii" jedhamuun hundeeffameera.
  • Iddoon hojii fi teessoon isaa Magaalaa Caffee Bantii ta'a.

Keewwata 2: Ulaagaalee Miseensummaa

  • Barataa Magaalaa Caffee Bantii keessatti dhalate, guddate ykn jiraatu ta'uu.
  • Sadarkaa barnootaa kamiyyuu irratti kan argamu (Kophaatti, Kolleejjii, Yuunivarsiitii).
  • Duudhaalee, Kaayyoo fi Imaammata gamtichaa fudhatee hojiirra oolchuuf kan waadaa gale.
  • Adaba naamusaa dhabuu irraa bilisa kan ta'e.

Keewwata 3: Mirga fi Dirqama Miseensotaa

Mirga Miseensotaa:

  • Sagantaalee fi leenjii gamtichi qopheessu irratti hirmaachuu.
  • Yeroo filannoo yaada kennuu, filachuu fi filatamuuf mirga qaba.
  • Deeggarsa barnootaa fi ogummaa gamtichi dhiyeessu irraa fayyadamuu.

Dirqama Miseensotaa:

  • Hojii tola ooltummaa fi sagantaalee gamtichaa irratti dammaqinaan hirmaachuu.
  • Buusii miseensummaa yeroo murtaa'etti kaffaluu.
  • Iccitii fi qabeenya gamtichaa eeguu.

Keewwata 4: Caasaa Hoggansaa

  • 1. Yaa'ii Waliigalaa: Qaama ol'aanaa murtoo dabarsu (Miseensota hunda).
  • 2. Koreen Raawwachiiftuu: Hoggansa Guyyaa guyyaa (Itti Aanaa, Barreessaa, Faayinaansii fi kkf).
  • 3. Koreen To'annoo fi Naamusaa: Hojii fi qabeenya kan to'atu.

Keewwata 5: Madda Galii fi Bulchiinsa Faayinaansii

  • Maddan galii: Buusii miseensotaa, deeggarsa abbootii qabeenyaa, fi gargaarsa dhaabbilee mootummaa/miti-mootummaa ta'a.
  • Baasiin kamiyyuu herrega baankii gamtichaa banameen iftoominaa fi hirmaachisummaan socho'a.

Keewwata 6: Naamusaa fi Adaba

Gochoota Naamusaa Cabsan:

  • Siyaasa fi Amantii: Kaayyoo gamtichaa dhiisee, dhimma amantii, sabaa, ykn siyaasaa calaqqisiisuu fi miseensota qoqqoduu.
  • Hirmaannaa Dhabuu: Sababa gahaa malee walga'ii, hojii tola ooltummaa, fi sagantaalee irraa deddeebi'anii hafuu.
  • Faayinaansii fi Qabeenya: Buusii yeroon kaffaluu dhiisuu, ykn qabeenya gamtaa faayidaa dhuunfaaf oolchuu.
  • Iccitii Eeguu Dhabuu: Iccitii hoggansaa fi marii gamtaa qaama alaatti dabarsanii kennuu.
  • Kabaja Waloorraa Maquu: Arraba, lola, ykn amala naamusaan alaa argisiisuu.

Sadarkaa Adabbii:

  • Sadarkaa 1ffaa: Gorsa fi Akeekkachiisa Afaanii (Oral Warning).
  • Sadarkaa 2ffaa: Akeekkachiisa Barreeffamaa (Written Warning).
  • Sadarkaa 3ffaa: Mirga Filachuu fi Filatamuu Dhorkamuu (yeroo murtaa'eef, fkn ji'a 3-6).
  • Sadarkaa 4ffaa: Miseensummaa Irraa Haqamuu (Expulsion - Yaada Koree Naamusatiin Yaa'ii Waliigalaan kan mirkanaa'u).

Qaama Adabbii Murteessu:

  • Koreen Naamusaa fi To'annoo (nama 3-5) dhimmoota naamusaa qoratee hoggansa ol'aanaaf yaada dhiyeessa.
  • Adabbii cimaa (miseensummaa irraa haquu) kan mirkaneessu Yaa'ii Waliigalaa gamtichaa qofa.
  • Miseensi adabbiin irratti murtaa'e Koree Raawwachiiftuuf ol-iyyata (appeal) dhiyeeffachuuf mirga qaba.

👨‍🏫 Naamusaa fi Walitti Dhufeenya Barsiisaa fi Barattootaa

Duudhaalee fi Amala Barataa irraa Eegamu:

  • Kabaja Ol-aanaa Argisiisuu: Barsiisota fi sadarkaa abbummaa isaanii kabajuu.
  • Ajajamuufi Qajeelfama Fudhachuu: Gorsa barnootaa fi naamusaa haala gaariin fudhachuu.
  • Giddu-galtummaa Siyaasaa fi Amantii: Amantii, siyaasa, ykn gosa dhiphoo calaqqisiisuu irraa of qusachuu.
  • Amala Barnootaa (Academic Integrity): Qorumsaa fi hojiiwwan irratti hattoomuu irraa bilisa ta'uu.

Dirqama fi Itti Gaafatamummaa Barsiisotaa:

  • Wal-qixxummaan barattoota hunda tajaajiluu fi madaaluu.
  • Barattoota rakkoo barnootaa fi dinagdee qaban gorsuufi jajjabeessuu (Mentorship).
  • Amala, qulqullina, fi yeroo kabajuun fakkeenya gaarii ta'uu.

Walitti Dhufeenya Daangaa Qabu fi Tarkaanfii Naamusaa:

  • Walitti dhufeenyi maallaqaa, kennaa seeraan alaa, ykn jaalalaa dhowwaadha.
  • Barataan mirga dhaggeeffatamuu fi mormii karaa nagaa dhiyeeffachuu qaba.
  • Barataa barsiisaa arrabyise/xiqqeesse irratti tarkaanfiin naamusaa cimaan kan fudhatamu ta'a.

💚 Deeggarsa

Gamtaa keenya hojii barattootaa fi hawaasaa keessatti deeggaruuf gumaacha keessan ni barbaanna.
